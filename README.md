# BMI Calculator — Body Mass Index Calculator

A simple Angular application to calculate **Body Mass Index (BMI)** and display health category results.

## Tech Stack

| Layer | Technologies |
|-------|-------------|
| Frontend | Angular, TypeScript |
| Styling | Bootstrap, CSS3 |

## Features

- Input height and weight (metric/imperial)
- Calculate BMI in real time
- Display health category (Underweight, Normal, Overweight, Obese)
- Visual indicator for BMI range
- Responsive design
